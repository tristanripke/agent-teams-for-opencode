# Changelog

## 0.2.0

First public release.

- Sessions list themselves, find each other and exchange messages through the `peers` tools: `discover`, `send`, `acknowledge` and `manage`.
- Teams of 1 to 32 sessions and temporary connections allow messaging across projects.
- Agent permissions set each capability to allow, ask or deny. Asking uses OpenCode's own approval prompt.
- OpenCode Desktop gets an Agent Teams panel with Teams, Agents, Connections, Messages and Activity, and a settings page.
- The terminal interface has the same actions through native dialogues.
- History is kept per team in OpenCode's own storage. There is no separate service or database.
